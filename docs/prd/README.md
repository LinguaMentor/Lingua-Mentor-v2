The PRD (`LinguaMentor-PRD.docx`) and the Phase 0 Calibration Brief (`LinguaMentor_Phase0_CalibrationBrief.docx`) live in this folder on the product owner's machine but are not committed. This repository is public, and both documents contain pricing, competitor and calibration material. `.gitignore` keeps them out.

The PRD is a living document, edited in place for product and technical decisions. Tickets on the [delivery board](https://github.com/orgs/LinguaMentor/projects/2) carry their full specification and never depend on the PRD; a section number may appear for traceability.

The Calibration Brief is written for the examiners and graders who run Phase 0. It matches the PRD's §9: two separate passes (TCF Canada and TCF IRN first, IELTS Writing second), the same multi-metric gate, and the same model-pinning discipline. Update it whenever §9 changes.
